# 🛒 Dynamic Shopping List

A simple, interactive shopping list built with vanilla HTML, CSS, and JavaScript. Add items using a form input, and remove them with a single click — no page reloads, no frameworks, no dependencies.

🔗 **Live Demo:** [https://integerconcept-data.github.io/Shopping-List/](https://integerconcept-data.github.io/Shopping-List/)

---

## ✨ Features

- **Add Items Easily:** Type an item and click **Add** — or just press **Enter**.
- **One-Click Delete:** Each item gets a **Delete** button that removes it instantly.
- **Auto-Focus Input:** After adding an item, the input is cleared and refocused, ready for the next entry.
- **No Page Refresh:** The form's default submit behavior is prevented, so the page never reloads.
- **Empty State Message:** Displays a friendly message when the list is empty.
- **Smooth Animations:** New items fade in gently for a polished feel.
- **Fully Responsive:** Looks great on desktop, tablet, and mobile.
